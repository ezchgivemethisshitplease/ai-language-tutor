# Веб-приложение

Приложение запускается на своём компьютере и открывается в обычном браузере. Нужны macOS или Linux, Python 3.10+, Node.js 22+ с npm 10+, интернет для установки зависимостей и работы преподавателя. Поддерживаются процессоры x64 и arm64. Актуальную LTS-версию Node.js можно взять на [nodejs.org](https://nodejs.org/en/download).

Из каталога проекта выполни:

```sh
./start.sh
```

Первый запуск создаёт `.venv`, устанавливает точные версии из `requirements.txt` и локальный официальный `@openai/codex` версии `0.163.0` из `package-lock.json`. Следующие запуски проверяют установленное окружение и используют его повторно. Для восстановления неполной или устаревшей установки launcher снова устанавливает соответствующие зависимости. `npm ci` восстанавливает весь проектный `node_modules` по lock-файлу, поэтому не храни там свои файлы. Глобальные npm-пакеты и настройки личного Codex launcher не меняет.

Браузер откроется на `http://localhost:8765/`. Сервер слушает только `127.0.0.1`; он предназначен для одного пользователя на этом компьютере. Если сервер уже работает для того же профиля, повторный запуск откроет его страницу. Остановка: `Ctrl+C` в терминале с сервером или:

```sh
.venv/bin/python tools/serve.py stop
```

## Вход и первое занятие

Нажми «Войти через ChatGPT» и продолжи на официальной странице входа OpenAI. Вход обслуживает отдельный локальный процесс Codex CLI; приложение не просит API-ключ и не читает учётные данные из личной установки Codex или Desktop. Для этого проекта CLI использует отдельный каталог `.runtime/codex-home`. Храни его как приватные данные, не публикуй и не добавляй в Git или учебные резервные копии. Локальный сервер получает состояние входа, а не токены.

Доступ к Codex и моделям зависит от аккаунта и его лимитов. Приложение получает доступные модели от CLI и показывает их в поле выбора под сообщением. Вход через ChatGPT и API-ключ имеют отдельные правила оплаты; подробности есть в [документации аутентификации Codex](https://developers.openai.com/codex/auth/). Самостоятельный CLI описан в [официальной документации Codex](https://developers.openai.com/codex/cli/).

Главная `index.html` показывает направления, последние разговоры, карточки к повторению и сохранённые результаты. Само занятие открывается в `chat.html`, а страница «Прогресс» показывает, по каким навыкам уже есть учебные наблюдения.

В разговоре открой «Язык и время занятий», укажи время и цели. Начни с «Найти отправную точку» для диагностики или выбери подходящее направление для практики. Переписка и учебные результаты сохраняются локально в `student/`. Кнопка «Скачать резервную копию» выгружает управляемые учебные файлы; состав и восстановление описаны в [инструкции резервного копирования](backup.md). Настройки автоматических копий действуют и для сохранений через веб-приложение.

Для общения с моделью запросы и история соответствующего разговора передаются сервису OpenAI через Codex. Карточки, чтение и упражнения открываются из бокового меню. Голосовой ввод использует локальный Whisper: запись превращается в редактируемый черновик, который вы отправляете сами. Ответ можно озвучить локальным голосом браузера. [Инструкция голоса](speech.md) описывает подготовку и работу с микрофоном. Текстовые расшифровки не служат оценкой произношения; для независимого учебного разбора речи остаётся отдельный голосовой маршрут.

Скачивание копии доступно в вебе. Восстановление ZIP в новую папку, аварийное восстановление JSON и фактический человеческий разбор для перехода выполняются через CLI по инструкциям проекта. Веб-преподаватель не может подписывать человеческий разбор или выдумывать прослушанное аудио. Диагностическое аудирование также требует внешнего маршрута с реальным звуком; обычный диктант в браузере остаётся доступным для практики. Экспериментальный [app-server](https://learn.chatgpt.com/docs/app-server) и динамические инструменты закреплены на версии `0.163.0`.

Человеческое сообщение сохраняется до запроса к модели. Неподтверждённую отправку повторяй кнопкой с тем же идентификатором; приложение не отправляет её заново автоматически. После перезапуска активный ответ считается прерванным, переписка остаётся в списке. При ошибке записи на диск новые сообщения блокируются: освободи место или исправь доступ и перезапусти сервер. Приложение не выдаёт запись в памяти за сохранённую историю. Если автоматическая копия недоступна, отдельное предупреждение не отменяет уже сохранённые ответы.

## Предпочтения и отдельные разговоры

«Мой подход» на главной открывает настройки «Как мне объяснять». По умолчанию преподаватель использует неформальный американский английский, простые объяснения с примерами, минимум грамматических терминов и сбалансированный разбор ошибок. Язык объяснений, вариант английского, стиль, темы и примечания можно изменить. Темы изначально пусты: приложение не приписывает тебе интересы по ответам в упражнениях.

Для каждого разговора отдельно сохраняются цель, темы, ситуация, формат и желаемая сложность. Можно выбрать повседневное общение, работу, поездки, интересы или собственную задачу, а затем уточнить контекст через «Настроить». Некоторые направления предлагают свой стиль, например деловой для работы. В дополнительных настройках можно вернуть наследование из профиля. Сохранённое направление может быть пустой беседой до первого сообщения; сохранение не отправляет текст модели.

Предпочтения учитываются в новых и существующих беседах. Если ответ уже начался, новые настройки применятся со следующего отправленного сообщения. Изменение стиля или темы не меняет уровень, оценки, интервалы повторения или исходные учебные ответы. Если другая вкладка уже изменила настройки, приложение покажет конфликт: проверь обновлённые значения и сохрани правки снова.

## Что преподаватель запоминает

В «Как мне объяснять» есть блок «Что запомнить для следующих занятий». Заметку можно добавить, исправить или удалить самому и выбрать область: все занятия либо только эта беседа. Преподаватель может предложить запомнить явно высказанное пожелание, указав исходное сообщение. Предложение остаётся неподтверждённым, пока ты сам не нажмёшь «Запомнить». Ролевые реплики, цитаты и ответы на задания не становятся фактами о тебе автоматически.

В следующий запрос модели входят текущие предпочтения, контекст разговора, общие подтверждённые заметки и заметки этой беседы. Заметки другого разговора туда автоматически не добавляются. Учебные результаты и общая статистика принадлежат всему профилю; это один пользователь с несколькими направлениями, а не отдельные изолированные аккаунты.

Удаление заметки исключает её из активной памяти для следующих сообщений. Оно не удаляет исходную переписку, уже переданный модели контекст или учебные наблюдения. В служебном журнале изменений остаются время, тип действия и контрольные суммы без текста удалённой заметки. История, настройки и управляемые заметки включаются в учебный ZIP-бэкап; вход Codex и его служебные разговоры туда не входят.

## Уроки, задания и прогресс

В профиле одновременно может быть один незавершённый учебный план. Он привязан к разговору, в котором начат. Можно открыть другой разговор для практики, но тот не сможет случайно записать ответ или завершить шаг чужого плана. Чтобы перенести тот же урок, нажми «Продолжить занятие здесь». Это явный перенос плана в открытый разговор. План и уже сохранённые результаты останутся прежними. Старый урок без привязки к чату, в том числе начатый через CLI, также требует явного переноса.

Текущее задание в разговоре показывает условие, варианты и критерии, без ключей и скрытого текста аудирования. Открытый ответ сначала сохраняется как исходный текст и может ожидать проверки. В данных последующий разбор преподавателя помечается как LLM; он не заменяет исходный ответ или человеческое подтверждение. Разные навыки на странице прогресса остаются непроверенными, пока для них нет подходящих наблюдений; показатели не являются сертификатом CEFR. Голосовая расшифровка остаётся подтверждённым текстом и не даёт оценки произношения или независимого письма.

После обновления набора инструментов старый разговор может получить новый служебный Codex-поток. Локальная переписка и результаты сохраняются; преподаватель получает текущие настройки и выбранную недавнюю часть истории. После обновления кода всё равно нужно перезапустить сервер.

## Параметры запуска

```sh
./start.sh --no-open              # запустить без открытия браузера
./start.sh --port 8877            # выбрать другой loopback-порт
./start.sh --port 0               # выбрать свободный порт; адрес появится в терминале
./start.sh --setup-only           # установить зависимости, не запускать сервер и вход
./start.sh --check                # проверить готовность без установки и запуска
./start.sh --help
```

`--check` печатает JSON и возвращает код `0`, если зависимости готовы, иначе `1`. Он проверяет версии Python-пакетов и метаданные локального npm runtime, но не выполняет вход, не обращается к модели и не подтверждает доступность аккаунта. `--help` работает до проверки зависимостей.

Если `python3` указывает на старую версию, выбери интерпретатор явно:

```sh
TUTOR_PYTHON=/path/to/python3.12 ./start.sh
```

Для отдельного учебного профиля можно задать `TUTOR_STUDENT_DIR`. Используй одно и то же значение при запуске, остановке и CLI-командах:

```sh
TUTOR_STUDENT_DIR=/path/to/private-student ./start.sh
TUTOR_STUDENT_DIR=/path/to/private-student .venv/bin/python tools/serve.py stop
```

Для разработки доступен `TUTOR_CODEX_BIN=/absolute/path/to/codex`. Такой override пропускает установку и проверку npm runtime; мост приложения всё равно проверяет совместимую версию CLI перед подключением. Для обычного запуска оставь эту переменную незаданной. `--check` с override проверяет только наличие исполняемого файла, а не его совместимость.

## Если запуск прервался

После обновления кода останови сервер командой выше и запусти `./start.sh` снова, затем обнови страницу. Уже работающий процесс продолжает использовать прежний код и настройки; одна перезагрузка браузера их не меняет. Учебные данные и история разговоров сохраняются.

При ошибке сети повтори `./start.sh`: неполная установка будет восстановлена. На Linux ошибка создания `.venv` может потребовать системного пакета `python3-venv`. Если сама `.venv` создана старым Python или указывает за пределы проекта, launcher остановится с объяснением; пересоздай только эту среду подходящим интерпретатором. Учебные данные для этого удалять не нужно.

После аварийного завершения может остаться `student/.serve.json`. Проверь `.venv/bin/python tools/serve.py status` и убедись, что старый сервер остановлен, прежде чем удалять устаревший control-файл. Сохранять старый токен для нового процесса нельзя. Если задан `TUTOR_STUDENT_DIR`, control-файл находится в этом каталоге.

Lock-файл фиксирует npm-артефакты и их integrity. Установка использует [`npm ci`](https://docs.npmjs.com/cli/v11/commands/npm-ci/) с отключёнными lifecycle-скриптами. Обновление версии Codex требует совместного изменения `package.json`, `package-lock.json` и проверки протокола моста; обычный запуск сам версию не повышает.
