# Английский с Codex или Claude Code

Тьютор объясняет на русском, даёт задания на английском и сохраняет выполненные попытки. Python управляет карточками, планом и прогрессом. Модель подбирает формулировки и разбирает открытые ответы. Её впечатление об уровне остаётся предварительным.

## Установка

Нужны Python 3.10+ и Codex или Claude Code с доступом к файлам и терминалу.

```sh
git clone https://github.com/ezchgivemethisshitplease/ai-language-tutor.git
cd ai-language-tutor
git switch improve/reliable-russian-tutor
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python tools/tutor.py init --native-language russian --daily-minutes 30
```

В Windows создайте окружение командой `py -m venv .venv` и запускайте `.venv\Scripts\python.exe` вместо `python`. Старые файлы ученика сохраняются; повреждённый JSON не заменяется пустым прогрессом. Перед обновлением ценных данных сделайте копию `student/`.

Откройте папку проекта в агенте и напишите: «Давай заниматься английским». Он прочитает общий AGENTS.md, загрузит местный humanize и начнёт диагностику. Установка личного скилла не нужна. Для продолжения достаточно «Давай заниматься» или `session`. Незавершённая сессия возвращается со своим сохранённым планом.

## Как проходит занятие

Тьютор показывает одно задание и ждёт ответ. Подсказка и исправленный ответ отмечаются отдельно от самостоятельной попытки. Несколько лёгких верных ответов не превращаются автоматически в освоенный раздел. Перечень слов старого профиля сохраняется как прежняя запись, а новые оценки опираются на выполненные задания.

Если формулировка допускает несколько вариантов, ваш ответ проверяется по смыслу. Например, `I love coffee` может подходить к контексту с ключом `like`; отсутствие варианта в ключе само по себе не доказывает ошибку. Для открытого текста тьютор различает грамматику, естественность, регистр и уместность.

Скажите «Объясни по-русски» на любом уровне. Поддержка русского постепенно меняется по результатам практики; просьба о русском действует всегда. База типичных затруднений помогает сравнить английскую конструкцию с русской, а диагноз появляется только после наблюдаемой ошибки.

Humanize редактирует речь самого тьютора: убирает дежурное «Отличная работа!», длинные подводки и повторяющиеся выводы. Ваши ответы, цитаты, числа и оценки он сохраняет дословно. Это инструкция по стилю; автоматического детектора «нейрослопа» здесь нет.

## Карточки и звук

```sh
python tools/serve.py
```

Откройте `http://localhost:8765/flashcards.html`. Сначала вспомните пропуск, затем откройте ответ и честно выберите оценку. «Не вспомнил» означает забытый ответ, «Трудно» означает успешное воспоминание с усилием. FSRS назначит следующее повторение. Каждая оценка сохраняется сразу. При сбое результат остаётся в очереди браузера; сообщение объясняет, что запись не подтверждена.

Тест, чтение и диктант запускаются после подготовки файла тьютором. Обычный голос браузера или macOS не требует платного API. Облачный TTS включается явно переменной `TUTOR_TTS` и получает озвучиваемый текст. Внешняя голосовая беседа получает подготовленный контекст занятия. Отчёт такой модели не доказывает качество произношения и не заменяет независимую оценку. Если голос недоступен, говорение остаётся непроверенным.

После занятия сервер останавливается командой `python tools/serve.py stop`. На общем компьютере учитывайте, что браузер хранит черновики и ожидающие отправки ответы.

## Свои данные

```sh
python tools/tutor.py export /safe/location/learner-export.json
python tools/tutor.py import /safe/location/learner-export.json /new/location/restored-student
python tools/tutor.py recover learner.json
```

Экспорт содержит личные данные и не шифруется. Импорт создаёт новую папку. Восстановление возвращает проверенную предыдущую версию JSON и сохраняет повреждённый файл отдельно. Ключи API храните в переменных окружения. Модель агента видит контекст, который читает во время занятия; локальное хранение не означает полностью офлайн-обучение.

В системе есть 60 планов уроков A1–C1 и небольшой банк диагностических заданий. Это не подтверждённая программа достижения C1. Переходы внутри курса требуют накопленных свидетельств и отдельного человеческого разбора. Для сертификации CEFR и готовности к реальному экзамену нужна внешняя оценка.
