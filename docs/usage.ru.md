# Английский в браузере

Тьютор объясняет на русском, даёт задания на английском и сохраняет выполненные попытки. Python управляет карточками, планом и прогрессом. Модель подбирает формулировки и разбирает открытые ответы. Её впечатление об уровне остаётся предварительным.

## Установка

Нужны macOS или Linux, Python 3.10+, Node.js 22+ и npm 10+.

```sh
git clone https://github.com/ezchgivemethisshitplease/ai-language-tutor.git
cd ai-language-tutor
git switch improve/reliable-russian-tutor
./start.sh
```

Откроется `http://localhost:8765/`. Нажмите «Войти через ChatGPT», затем «Продолжить вход» и завершите обычный вход OpenAI по своей подписке. Desktop не требуется. Приложение установит отдельный Codex CLI и будет хранить его вход в приватной `.runtime/codex-home`. Личный профиль Codex оно не копирует. API-ключ не нужен; действуют доступ и лимиты вашего аккаунта.

В «Мой профиль» задайте время и цель. Дальше можно выбрать диагностику, начать занятие или написать преподавателю. Здесь же доступны история, план, пауза, карточки, упражнения, чтение, диктант, прогресс и скачивание копии данных. Чат получает humanize и правила обучения прямо из проекта. Закрытие вкладки не стирает сохранённый разговор; при следующем открытии можно продолжить его из списка.

Мост использует экспериментальный app-server Codex `0.163.0`; версия закреплена. Для голосового общения есть микрофон с локальным Whisper и кнопка «Озвучить». Расшифровку нужно проверить и отправить самому; модель получает текст, без оценки произношения. [Настройка голоса](speech.md) описывает установку и приватность. Восстановление архива, человеческий разбор и аварийное восстановление JSON пока запускаются командами ниже. [Инструкция веб-приложения](web.md) содержит параметры запуска и разбор ошибок.

Можно продолжать пользоваться Codex или Claude Code с доступом к файлам и терминалу. Для этого достаточно Python-ядра:

```sh
git clone https://github.com/ezchgivemethisshitplease/ai-language-tutor.git
cd ai-language-tutor
git switch improve/reliable-russian-tutor
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python tools/tutor.py init --native-language russian --daily-minutes 30
```

Старые файлы ученика сохраняются; повреждённый JSON не заменяется пустым прогрессом. Перед обновлением ценных данных сделайте копию `student/`.

Откройте папку проекта в агенте и напишите: «Давай заниматься английским». Он прочитает общий AGENTS.md, загрузит местный humanize и начнёт диагностику. Установка личного скилла не нужна. Для продолжения достаточно «Давай заниматься» или `session`. Незавершённая сессия возвращается со своим сохранённым планом.

## Как проходит занятие

Тьютор показывает одно задание и ждёт ответ. Подсказка и исправленный ответ отмечаются отдельно от самостоятельной попытки. Несколько лёгких верных ответов не превращаются автоматически в освоенный раздел. Перечень слов старого профиля сохраняется как прежняя запись, а новые оценки опираются на выполненные задания.

Если формулировка допускает несколько вариантов, ваш ответ проверяется по смыслу. Например, `I love coffee` может подходить к контексту с ключом `like`; отсутствие варианта в ключе само по себе не доказывает ошибку. Для открытого текста тьютор различает грамматику, естественность, регистр и уместность.

Скажите «Объясни по-русски» на любом уровне. Поддержка русского постепенно меняется по результатам практики; просьба о русском действует всегда. База типичных затруднений помогает сравнить английскую конструкцию с русской, а диагноз появляется только после наблюдаемой ошибки.

Humanize редактирует речь самого тьютора: убирает дежурное «Отличная работа!», длинные подводки и повторяющиеся выводы. Ваши ответы, цитаты, числа и оценки он сохраняет дословно. Это инструкция по стилю; автоматического детектора «нейрослопа» здесь нет.

## Карточки и звук

```sh
python tools/serve.py
```

Откройте `http://localhost:8765/flashcards.html`. Сначала вспомните пропуск, затем откройте ответ и честно выберите оценку. «Не вспомнил» означает забытый ответ, «Трудно» означает успешное воспоминание с усилием. FSRS назначит следующее повторение. Каждая оценка сохраняется сразу. При сбое результат остаётся в очереди браузера; сообщение объясняет, что запись не подтверждена.

Тест, чтение и диктант запускаются после подготовки файла тьютором. Обычный голос браузера или macOS не требует платного API. Облачный TTS включается явно переменной `TUTOR_TTS` и получает озвучиваемый текст. Внешняя голосовая беседа получает подготовленный контекст занятия. Отчёт такой модели не доказывает качество произношения и не заменяет независимую оценку. Если голос недоступен, говорение остаётся непроверенным.

Сервер веб-чата оставляйте запущенным, пока занимаетесь. Остановка: `Ctrl+C` в терминале или `.venv/bin/python tools/serve.py stop`. На общем компьютере учитывайте, что браузер хранит черновики и ожидающие отправки ответы.

## Свои данные

```sh
python tools/tutor.py backup /existing/safe/location/learner.zip
python tools/tutor.py backup-check /existing/safe/location/learner.zip
python tools/tutor.py restore /existing/safe/location/learner.zip /new/location/restored-student
python tools/tutor.py recover learner.json
```

Архив сохраняет управляемые файлы всех языков и ваши изображения/записи. В нём есть личные данные, автоматического шифрования нет. Восстановление проверяет весь архив и создаёт новую папку, не заменяя существующую. Старые команды `export`/`import` сохраняют прежний формат для активного английского профиля. Восстановление возвращает проверенную предыдущую версию JSON и сохраняет повреждённый файл отдельно. Ключи API храните в переменных окружения. Модель агента видит контекст, который читает во время занятия; локальное хранение не означает полностью офлайн-обучение.

Для копий на своём диске задайте `TUTOR_BACKUP_DIR` как существующую папку. По умолчанию сохраняются 7 версий с интервалом не чаще 24 часов; проверка запускается после изменения учебных данных. `TUTOR_BACKUP_REQUIRE_MOUNT` позволяет потребовать подключённый внешний диск. Фоновая служба не устанавливается. При недоступном диске ответ всё равно остаётся сохранённым, а тьютор сообщает о проблеме копирования. [Политика копирования](backup.md) описывает состав архива и команды.

В системе есть 60 планов уроков A1–C1 и 100 оригинальных диагностических заданий. Для продолжающих предусмотрен предварительный выбор материалов по чтению и реальному аудированию: `placement --target-level B1` показывает, каких данных не хватает, а `accept-placement` принимает маршрут только после прохождения условий. Он не записывает непроверенные разделы как освоенные. Письмо и говорение учитываются отдельно, ключи и аудиоскрипты скрыты в обычной выдаче заданий. [Диагностика](assessment.md) содержит точные условия. Это не подтверждённая программа достижения C1. Переходы внутри курса требуют накопленных свидетельств и отдельного человеческого разбора. Для сертификации CEFR и готовности к реальному экзамену нужна внешняя оценка.
