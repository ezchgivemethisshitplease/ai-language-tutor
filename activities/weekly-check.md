# Activity: periodic formative check

Use the current session/step and the shared CLI write-back workflow. Select recent skills plus delayed items in a fresh context. Include reading, writing, actual listening and actual speaking when available. Missing audio modalities remain unassessed and do not become zero scores or typed substitutes.

Generate constrained questions with accepted alternatives and open prompts with explicit rubrics. Offer no hints until each independent trial is recorded; assisted follow-up practice uses `--hints-used`. Preserve AI/human provenance. Use explicit error tags only when supported by the answer and context. Ask for Russian explanations whenever needed.

Run `tutor.py assess` to report observations, uncertainty and gaps. Describe one concrete improvement only if earlier comparable evidence exists. Choose the next objective from errors, forgetting risk and under-practised skills. This check does not change levels or certify CEFR; it supplies evidence to the ordinary planner and readiness gate.
