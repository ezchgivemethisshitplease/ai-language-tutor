# Голос в веб-чате

Кнопка микрофона записывает фразу и распознаёт её локально через [whisper.cpp](https://github.com/ggml-org/whisper.cpp/tree/v1.9.5). Codex получает подтверждённый вами текст. Аудио ему не передаётся. Ответ можно прослушать кнопкой «Озвучить»: используются только установленные локальные голоса браузера.

## Подготовка

Откройте настройки голосового ввода рядом с полем сообщения. Если компоненты отсутствуют, нажмите кнопку установки. Подготовка запускается только по вашему действию; обычный запуск текстового чата ничего речевого не скачивает. Те же команды в терминале:

```sh
.venv/bin/python tools/speech.py setup
.venv/bin/python tools/speech.py status
```

Для сборки нужны Git, CMake и компилятор C++. На macOS подходят Command Line Tools, на Linux — комплект сборки вашего дистрибутива. Проверка покажет недостающие инструменты. Установка собирает закреплённый `whisper.cpp 1.9.5` и загружает многоязычную модель base размером 147 951 465 байт с проверкой SHA-256. Файлы лежат в игнорируемой `.runtime/speech`. Глобальные Python-пакеты и Torch не устанавливаются. На macOS используется Metal, на Linux — CPU. Если FFmpeg отсутствует, загрузится приватный проверенный бинарный файл из wheel `imageio-ffmpeg 0.6.0`, без установки пакета в Python.

Интернет нужен для получения компонентов. Распознавание работает локально без ключа и облачного STT. Чат с Codex по-прежнему обращается к OpenAI и требует входа по подписке.

## Запись и отправка

1. Настройте профиль и войдите через ChatGPT для работы с преподавателем.
2. Нажмите микрофон и разрешите этому локальному сайту доступ. До нажатия приложение не запрашивает разрешение и не записывает звук.
3. Скажите фразу и остановите запись. Предел — 60 секунд и 12 МиБ. Можно выбрать английский, русский или автоопределение.
4. Проверьте текст. В пустом неизменённом поле он появится как черновик; при уже введённом тексте или переключении разговора появится отдельный редактируемый результат с явным добавлением. Сообщение самостоятельно не отправляется.
5. Нажмите обычную кнопку отправки, когда текст соответствует тому, что вы хотите сказать.

Запись можно отменить. При сетевой ошибке аудио остаётся в памяти вкладки для явного повтора; перезагрузка его теряет. Отмена ожидания в браузере не всегда останавливает уже начатую серверную обработку: она заканчивается в пределах своего лимита, затем временные файлы удаляются. До завершения следующий запрос может попросить подождать. Остановка сервера завершает принадлежащие ему речевые процессы.

Для «Озвучить» доступны английский, русский и выбор по языку текста. Во время записи озвучивание останавливается. Если локального голоса нужного языка нет, приложение объяснит это; удалённый голос молча не подключается. При необходимости установите голос средствами ОС.

## Данные и оценки

Запись не добавляется в историю аудио или учебный архив. Временные файлы удаляются после обработки. Добавленная в поле сообщения расшифровка сохраняется в браузерном черновике; отдельный результат до добавления хранится только в памяти вкладки и теряется при перезагрузке. После отправки сохраняется точный текст и происхождение `whisper_transcript`. Этот признак остаётся после редактирования и повтора. Пустое новое поле снова считается обычным текстовым вводом.

Расшифровка не доказывает произношение, понимание речи на слух или самостоятельное письмо. Её нельзя засчитать как письменную продуктивную попытку. Обсуждать ситуации и тренировать разговор с озвучиванием можно; акустическую оценку и человеческий разбор эта связка не выполняет. Внешний голосовой учебный маршрут остаётся отдельно.

## Проверка

На macOS arm64 реально собраны нативные компоненты и проверены контрольные суммы. Синтезированные английская и русская фразы распознаны с явным и автоматическим языком; проверены WAV, WebM/Opus, Ogg/Opus, MP4/AAC и защищённый HTTP-маршрут. Частный FFmpeg fallback тоже запускался. Настоящий микрофон в QA не включался. Linux-сборку, шум, акценты, длинные записи и наличие голосов на других системах ещё нужно проверять отдельно. Это проверка работоспособности, а не заявленная точность распознавания.
